Install in three steps

  1. Download the APK and allow your browser to install this app from this source when Android asks.
  2. Open DonkeyRide Driver and allow location while you are working.
  3. Tap Go Online. A persistent on-shift notification means the app can keep receiving work with the screen off.

Going Offline stops shift tracking. Force-stopping the app also ends the live shift. Direct mode does not provide off-shift push alerts.

Your phone holds your identity

Rider, driver, trip and shift identities are derived locally from an encrypted identity tree. The public app has no DonkeyRide database. Relays and routing services can still observe network timing, IP addresses and the route data sent to them, so this is privacy-minimised rather than anonymous.

Verify the APK checksum before installing if you received the file from somewhere else.
