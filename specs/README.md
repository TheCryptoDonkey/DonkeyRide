# TROTT Protocol Specifications

The TROTT protocol specifications have moved to their own repository:

**https://github.com/TheCryptoDonkey/trott**

This includes:
- Core specifications (TROTT-01 through TROTT-08)
- Domain profiles (ridesharing, locksmith, delivery, towing, emergency trades, pet services, security, cleaning, moving)
- Implementor guides (build-a-*-app)
- Protocol documentation (architecture, trust mechanisms, staking, interoperability, etc.)
- Design rationale and historical NIP-XX archives

DonkeyRide remains the **reference implementation** of the TROTT protocol. For implementation-specific documentation, see the [docs/](../docs/) directory.
